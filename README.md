# Split Mate 🏠💸

**Split Mate** es una aplicación pensada para que las personas que comparten piso puedan llevar las finanzas y las facturas del hogar de forma más organizada y en un solo lugar.

## ¿De qué va el proyecto?

Compartir piso implica gestionar gastos comunes: alquiler, luz, agua, internet, la compra, etc. Normalmente esto se hace con mensajes sueltos, notas o hojas de cálculo, lo que provoca confusión, olvidos y discusiones.

Split Mate centraliza toda esta información para que los compañeros de piso puedan:

- Registrar los gastos y facturas compartidas del piso.
- Saber en todo momento quién ha pagado qué y cuánto debe cada uno.
- Dividir los gastos de forma justa entre los integrantes del piso.
- Tener un historial claro y accesible de todas las cuentas del hogar.

El objetivo es simplificar la convivencia en lo económico, haciendo las cuentas transparentes y evitando malentendidos entre compañeros.
